# День 2 — компактный итог

Подготовлены [правила проекта](../../docs/agent-project-rules.md) и профили
[Research v1](../../docs/agent-profiles/research.md),
[Bug Fix v1](../../docs/agent-profiles/bug-fix.md). Каждый профиль проверен
в отдельном контексте; основной агент дополнительно проверил поведение.

| Проверка | Исторический результат |
|---|---|
| Research: путь авторизации и изоляция владельца | Ответ принят с первой попытки; 15/15 тестов, exit 0; исходники не менялись |
| Bug Fix: верхняя граница даты старта | Первый фикс без переделки; `./scripts/pnpm.sh check`: 24/24, типы, lint, build, exit 0 |
| Прямой POST на сегодня +8 | До фикса 201 с записью; после 422 без записи |
| Браузер | +7 сохраняется, +8 блокируется; loading/error/retry и задержанные ответы проверены |
| Независимое ревью | P1/P2 нет; P3: неверно разрешён относительный путь security-checklist в пояснении Research |

Автономность исполнителей и успех первого решения оценивались отдельно:
оба запуска самостоятельные, основные решения приняты с первого раза.
Первоначальный tsx IPC EPERM был ограничением sandbox до исполнения тестов;
разрешённый повтор успешен. Это не падение продуктовой проверки.

После эксперимента отдельным запросом запрещены прошлые даты. Текущий диапазон:
серверное сегодня…сегодня +7 включительно в часовом поясе челленджа.
Сервис отклоняет вчера/+8 с 422 до INSERT; сегодня/+7 принимаются.
Повторный полный check: 24/24, exit 0. В браузере проверены min/max,
блокировка недопустимого submit и обе сохранённые границы. Прямой fill поля
даты мог отличаться от обновления состояния формы; сохранение допустимых
дат подтверждено клавиатурным вводом. Схема SQLite v2 и прежние записи сохранены.
Актуальные регрессии: [tests/start-date.test.ts](../../tests/start-date.test.ts).

Профили после измеряемых запусков не дорабатывались. Рекомендация будущей
итерации Research: разрешать относительные ссылки от каталога SKILL.md
перед утверждением об отсутствии ресурса. Исходная оценка не исправлялась задним числом.
Применялись api-and-interface-design, security-and-hardening,
frontend-ui-engineering, openai-docs и browser-testing-with-devtools;
при отсутствии DevTools MCP использовался доступный браузерный инструмент.
Реальный Telegram WebView, screen reader и нагрузка не проверялись.

По запросу пользователя промежуточные логи, снимки, патчи, manifests и копии
кода удалены; этот документ сохраняет сводку, но не заменяет сырые доказательства.
Материалы Дня 1 не изменялись.
