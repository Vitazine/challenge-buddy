## Принятый API-контракт

- `GET /api/challenges?page=1&pageSize=20&archived=false`: обычный список по умолчанию. `archived=true` выбирает только архив того же подтверждённого владельца. `total`, `items` и пагинация относятся к выбранному списку. Параметр принимает только `true`/`false`; неизвестные/некорректные параметры — 422. Сохраняются пределы pageSize 1–50.
- `PUT /api/challenges/:id/archive`: без тела либо `{}`; поля тела не принимаются. Возвращает 200 и `Challenge`. Повторный запрос не меняет первоначальный `archivedAt` и безопасен для повторения.
- `Challenge.archivedAt`: `null` для обычного челленджа либо строка ISO UTC для архивного. `status` остаётся календарным; даты, `checkIns` и `progress` не изменяются при архивировании. `canCheckIn` в архиве всегда false.
- `GET /api/challenges/:id` продолжает возвращать владельцу архивные детали.
- PUT/DELETE `/api/challenges/:id/check-ins/today` для архива возвращают 409 `ARCHIVED`, без изменения истории.
- Новый маршрут использует существующую подтверждённую идентичность. Чужой и отсутствующий объект — одинаковый 404 `NOT_FOUND`; нет входа — 401; некорректный UUID — 422. Формат ошибок прежний `{ error: { code, message } }`.
