но после submit сохранилось сегодня. В первой проверке также была неверная
ожидаемая подпись заголовка, однако несоответствие даты подтверждалось отдельно.

предположение, а не доказанная причина. Код продукта ради повтора не менялся.

после остановки временные БД удалены. Применялся browser-testing-with-devtools
с доступным расширением; DevTools MCP отсутствовал.

exit 0. После переключения HTTPS health →200, защищённый API без авторизации
→401; публичные файлы совпали со сборкой, схема осталась v2. Применялся vps-admin.
